# AlbionPersonal AI Calisma Kurallari

Bu projede kalici AI kayit sistemi kullanilir. Her oturum basinda asagidaki
dosyalar proje baglami olarak okunur:

- `AGENTS.md`
- `docs/ai/AI_HANDOFF.md`
- `docs/ai/AI_SESSION_LOG.md`
- `docs/ai/AI_CONTEXT_INDEX.md`

Calisma kurallari:

- Kod yazmadan once mevcut proje yapisini incele.
- Var olan mimariyi bozmadan ilerle.
- Buyuk veya riskli degisikliklerde once kisa plan cikar.
- Gereksiz refactor yapma.
- Kullanilmayan yeni bagimlilik ekleme.
- Tahmin ettigin seyleri kesin bilgi gibi yazma.
- Emin olmadigin konulari acik sorulara ekle.
- Gizli bilgi, API key, token, sifre, connection string veya kisisel erisim
  bilgisi kayit dosyalarina yazilmaz.
- Hassas bilgi gorursen kayit dosyalarina kopyalama.

Oturum sonunda onemli degisiklikler icin `docs/ai` altindaki handoff, session
log ve context index dosyalari guncellenir.
